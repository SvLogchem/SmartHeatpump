# SmartHeatpump voor Home Assistant

Een geavanceerde, zelflerende weersafhankelijke regeling met zonnecompensatie en compressor-bescherming (waakhond) voor warmtepompen (speciaal geoptimaliseerd voor lokaal aan te sturen systemen zoals Tuya Local).

## Functies
- **Slimme Stooklijn:** Combineert actuele buitentemperatuur, weersvoorspelling (anticipatie) en zonnestand (elevatie).
- **Flexibele Regeling:** Keuze tussen sturen op Aanvoer- of Retourtemperatuur.
- **Compressor Waakhond:** Voorkomt te vroeg afslaan (pendelen) tijdens de eerste opstartminuten.
- **Lokaal & Privacyvriendelijk:** Volledig lokaal aan te sturen via Home Assistant.
